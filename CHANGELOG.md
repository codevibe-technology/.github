# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 2026-11-11

### Changed

- Organization profile README: the X badge points to [@codevibe_in](https://x.com/codevibe_in) (the account was renamed from @codevibencr), the npm badge opens the `codevibe_technology` npm organization page, and links to codevibe.in carry UTM tags (`utm_source=github`, `utm_medium=org-profile`, `utm_campaign=github-org`, `utm_content` for the link position) so visits from the profile can be measured.

### Fixed

- `brand/social/`: the asterisk in the Codevibe mark had an extra top-right arm. It now matches the official logo (the corner bracket sits where that arm was). All five PNGs and SVGs are re-exported.

### Added

- `brand/`: social media kit in the Codevibe brand system. Banners for YouTube (2560x1440, text inside the 1546x423 safe area), X (1500x500) and LinkedIn (2256x382, the 1128x191 cover at 2x), a square avatar (800x800) and a YouTube watermark (300x300). Each comes as a PNG ready to upload and a self-contained SVG source with the fonts inlined.
- Organization profile README (`profile/README.md`): what we build, our open-source packages, the stack we work in, how we work and how to reach us.
- Profile banner (`profile/banner.svg`) in the Codevibe brand system, with the fonts subset and inlined.
- Repository README and this changelog.
