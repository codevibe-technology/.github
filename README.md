# codevibe-technology/.github

The public profile and shared community files for the [Codevibe Technology](https://github.com/codevibe-technology) GitHub organization.

- `profile/README.md` is the page visitors see at [github.com/codevibe-technology](https://github.com/codevibe-technology).
- `profile/banner.svg` is the banner at the top of it: a single self-contained SVG with the brand fonts subset and inlined, so it renders the same everywhere.

Changes are recorded in [CHANGELOG.md](CHANGELOG.md).
